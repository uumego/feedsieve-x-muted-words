# FeedSieve → X 批量隐藏词

这是一个 **Tampermonkey（油猴）用户脚本**，用于管理一套本地关键词词库，并将其中尚未存在的关键词分批添加到 X（Twitter）的“已隐藏的字词”中。

> 这不是 Chrome 扩展，也不是 X 官方功能。它依赖 Tampermonkey / Violentmonkey 这类用户脚本管理器运行。

## v4 的变化

从 v4 开始，脚本**不再运行时访问 FeedSieve 网站获取最新词库**。

脚本固定绑定 FeedSieve 官方仓库的 **2026.09.13.2 词库快照**，包含当前使用的“黄推 / 成人引流”和“Crypto scam giveaway”规则。该快照地址固定到具体 Git commit，因此不会随着 FeedSieve 后续更新自动变化。

这样做的优点：

- 不依赖 feedsieve.win 是否可访问
- 不受 X CSP 跨域限制影响
- 不会因为上游词库突然变化而改变本地行为
- 安装后可以自行维护关键词

## 功能

- 固定内置关键词快照
- **关键词管理面板**
- 搜索关键词
- 添加自定义关键词
- 删除 / 停用内置关键词
- 删除自定义关键词
- 恢复全部被停用的内置关键词
- 导出当前启用词库为 TXT
- 自动扫描 X 当前已经添加的隐藏词
- 自动排除已经存在的词，避免重复添加
- 对大小写、空格及“关键词 + 中文说明”这类变体做归一化匹配
- 每次只添加一小批，降低触发 X 临时限制的概率
- 自动保存本地成功/失败记录，方便中断后继续
- 连续失败时自动停止，避免持续撞限流

## 使用环境

- Chrome / Edge / 其他 Chromium 浏览器
- 已安装 Tampermonkey（油猴）或兼容的用户脚本管理器
- 已登录 X 账号

## 安装方法

1. 安装 Tampermonkey（油猴）。
2. 打开 Tampermonkey，选择“添加新脚本”。
3. 删除默认内容。
4. 复制本仓库中的 `feedsieve-x-muted.user.js` 全部内容并粘贴进去。
5. 保存脚本。
6. 打开 X：
   `设置和隐私 → 隐私和安全 → 隐藏并屏蔽 → 已隐藏的字词`
7. 页面右下角会出现 **FeedSieve → X v4** 操作面板。

## 关键词管理

点击右下角的 **管理关键词**。

管理窗口中可以：

- 搜索当前词库
- 在输入框中添加一个或多个关键词
- 一行一个，或用逗号、分号分隔
- 删除自定义关键词
- 停用某个内置关键词
- 恢复被停用的内置关键词
- 一键恢复全部内置关键词
- 导出当前启用关键词为 TXT

### 删除内置关键词是什么意思？

为了保留原始内置快照，删除内置关键词实际上是将它标记为“停用”。以后批量添加时不会再使用它。

这**不会自动删除 X 中已经添加的隐藏词**。如果某个词已经存在于 X，需要在 X 自己的“已隐藏的字词”页面里手动删除。

### 自定义关键词

用户添加的关键词会保存在 Tampermonkey 本地存储里，不会修改仓库里的原始词库，也不会上传到任何服务器。

## 推荐使用流程

1. 打开 X 的“已隐藏的字词”页面。
2. 如有需要，先点击 **管理关键词** 调整词库。
3. 点击 **扫描全部已添加**，确认脚本能正确识别当前已有隐藏词。
4. 点击 **扫描并添加下一批**。
5. 脚本会先把当前启用词库与 X 已有词进行比对，只添加缺少的词。
6. 如果 X 开始拒绝添加，脚本会在连续失败后自动停止。
7. 等到手动添加恢复正常后，再继续下一批。

## 去重逻辑

脚本会同时使用完整文本和简化关键词进行比较，尽量避免格式差异造成重复添加。

例如下面这些会尽量视为同一类关键词：

- `adult`
- `ADULT`
- `adult  成年人`

真正执行添加前还会再做一次检查。

## 关于 X 的添加限制

X 没有公开说明“隐藏词”具体允许连续添加多少条。

实际使用中，连续快速添加较多隐藏词后，可能出现临时无法继续添加的情况，甚至手动添加也会暂时失败。因此本脚本默认：

- 每批最多添加 15 条
- 每条之间随机等待几秒
- 连续失败 2 次后自动停止

不建议为了追求速度大幅提高批量数量或缩短间隔。

## 本地数据

Tampermonkey 本地存储中会保存：

- 用户自定义关键词
- 被用户停用的内置关键词
- 已成功添加记录
- 添加失败记录
- 最近一次运行时间

“清除导入进度”只清除成功/失败/运行记录，不会清除用户自定义词库，也不会恢复被停用的内置词，更不会删除 X 里的隐藏词。

## 词库来源与固定版本

内置词库来自 FeedSieve 官方开源仓库：

- 固定版本：`2026.09.13.2`
- 使用分类：`adult_gray_traffic`、`crypto_giveaway_scams`
- 使用固定 Git commit 快照，不自动跟随上游变化

脚本不会在每次运行时请求 FeedSieve 网站更新词库。

## 隐私说明

脚本在你的浏览器本地运行。

它会：

- 读取 Tampermonkey 安装时缓存的固定词库资源
- 读取并操作 X 的“已隐藏的字词”设置页面
- 在 Tampermonkey 本地存储中保存用户设置与导入进度

它不需要你的 X 密码，也不会把账号密码、Cookie、登录凭据、自定义关键词上传到本项目。
